## Featured Projects

### Vitalmatch — Blood Donation Coordination System
> Top 3 · Enyata × Interswitch Buildathon (500+ submissions, 1,000+ registrants)

A Django REST API powering a full blood donation lifecycle — donor matching
by blood group, genotype, and proximity, with retry and radius-expansion logic
when donors don't respond. Sensitive contact details are only exposed
post-acceptance.

[View Repository](https://github.com/OlajideTechie/vitalmatch-buildathon)

---

### Kowope — Driver Ticketing & Payment Platform

A backend system handling the full ticket lifecycle for transport agents —
Paystack payment gating, QR code generation, and dual offline/online
verification paths for low-connectivity environments. Ticket state management
prevents duplicate validation and fraudulent reuse.

[View Repository](https://github.com/OlajideTechie/kowope-backend)

---

### FastPay API — Payment Processing Backend

Full Paystack integration with idempotent webhook handlers, signature
verification, explicit failure state modelling, and transaction reconciliation
against Paystack's own records on ambiguous callbacks. Covered with automated
tests across payment validation and edge cases.

[View Repository](https://github.com/OlajideTechie/FastPay-Project)
